# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Instead,
contact the repository owner privately through the contact options on the
[GitHub profile](https://github.com/zfeder).

Include:

- affected SwiftSurf version
- macOS version
- clear reproduction steps
- security impact
- a suggested fix, if available

Please do not include passwords, session cookies, private URLs, or other
sensitive data in a report.

## Scope

SwiftSurf embeds WebKit and therefore inherits security behavior from the
installed macOS WebKit release. Keep macOS updated when using SwiftSurf.
